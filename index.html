Source: the three user-supplied Police UK workbooks, as consolidated into the historical JSON dataset. Figures include anti-social behaviour. Six-year baselines use the six preceding years for the same calendar month (2026: 2020–2025). Percentage differences are descriptive, not adjusted for population or changes in reporting. This dashboard contains ward-level counts only; it cannot plot individual crime locations without separate anonymised street-level data. The dataset is embedded so the dashboard works locally and on GitHub Pages without live Police API calls.
