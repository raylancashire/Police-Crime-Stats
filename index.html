ZIP contains one JSON file per ward/month, a combined JSON file and a manifest listing successes and failures. You can export partial results at any time. Missing months are never treated as zero.

How this works

The Police API is queried separately for each ward and month, using the ward's official boundary. Records are assigned to a ward using their published approximate coordinates. Requests are sequential, with a delay and retries for temporary errors. This tool does not need an API key.

Source: Police UK street-level crime API. The map points are anonymised and may differ from the actual offence location. Your existing Excel monthly totals remain the reference for your historical analysis.
